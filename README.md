# Weather App

A simple weather app made with HTML, CSS, and JavaScript. It uses the OpenWeatherMap API to fetch live weather data for any city you search.

## Features
- Search weather by city name
- Shows temperature, weather description, and icon
- Press Enter or click the search button to get results

## How to use
1. Download or clone this repo
2. Open `index.html` in your browser
3. Type a city name and hit search


## Files
- `index.html` — page structure
- `style.css` — styling
- `script.js` — fetches weather data and displays it

## Tech used
- HTML
- CSS
- JavaScript (Fetch API)
- OpenWeatherMap API
